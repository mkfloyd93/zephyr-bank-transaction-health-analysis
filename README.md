# Zephyr Bank Transaction Health Analysis

Data analytics portfolio project based on the DataDNA UK Fintech
Neobank Digital Transaction Health Monitor challenge.

## Objective

Analyze Zephyr Bank's H1 2026 transaction data to identify transaction
friction, fraud exposure, and fee revenue leakage, and provide actionable
recommendations for Risk, Product, Finance, and Compliance stakeholders.
